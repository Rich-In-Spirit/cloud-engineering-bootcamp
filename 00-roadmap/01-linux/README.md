## Focus Areas

- Filesystem navigation
- Users and groups
- Permissions
- Package management
- Services
- Logs
- Networking tools
- SSH
- Bash scripting
- Troubleshooting

## Lab Rule

Every Linux lab must include:
- Objective
- Commands used
- What happened
- What broke or confused me
- What I learned
