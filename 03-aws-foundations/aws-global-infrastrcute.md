# AWS Global Infrastructure

## Region

A Region is a physical geographic area where AWS has multiple data centers grouped into Availability Zones.

Example:
- us-east-1
- us-east-2
- us-west-2

## Availability Zone

An Availability Zone is one or more data centers inside a Region.

Availability Zones are separated from each other so that if one has a problem, another can keep running.

## Edge Location

An Edge Location is used to deliver content closer to users, usually through services like CloudFront.

## Why this matters

Cloud engineers need to understand Regions and Availability Zones because they affect:

- Latency
- High availability
- Disaster recovery
- Cost
- Compliance
- Architecture design

## Plain-English explanation

A Region is the city/area.
An Availability Zone is a separate building or campus inside that area.
Edge Locations are smaller distribution points closer to users.
