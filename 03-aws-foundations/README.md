# AWS Foundations Labs

This folder documents AWS cloud engineering labs.

## Focus Areas

- AWS account setup
- IAM
- MFA
- Regions and Availability Zones
- VPC
- Subnets
- Route tables
- Internet gateways
- Security groups
- EC2
- S3
- AWS CLI
- Cost controls

## Lab Rule

Every AWS lab must include:
- Objective
- Services used
- Architecture
- Steps taken
- Security considerations
- What broke or confused me
- Cleanup steps
